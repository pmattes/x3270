The presence of this file in the same directory as wc3270.exe, wc3270wiz.exe
(the wc3270 Session Wizard), s3270.exe, b3270.exe, or pr3287.exe causes
the emulator to run in Portable Mode. In Portable Mode, the emulator will
generally not read or write files outside of that directory. The only
exception is that the Session Wizard can still create shortcuts on the
user's Desktop.

To turn off Portable Mode, remove this file, or run the emulator with the
-noportable command-line option.
